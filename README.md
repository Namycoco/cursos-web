✨ Sobre el proyecto

Cursos Web es un proyecto personal desarrollado para poner en práctica mis conocimientos de diseño y desarrollo web frontend.

La idea del proyecto es crear una página web moderna, visual y funcional que pueda servir como plantilla de prueba y muestra de mis capacidades ante empresas y futuros proyectos profesionales.

El objetivo no es únicamente que la página funcione, sino también cuidar aspectos como la estructura, diseño visual, organización del contenido, experiencia de usuario y adaptación a diferentes dispositivos.

💻 Visualización local

Si quieres ejecutar el proyecto en tu propio ordenador:

git clone https://github.com/namycoco/cursos-web.git


Después, abre el archivo index.html en tu navegador.

También puedes utilizar Visual Studio Code junto con una extensión como Live Server para visualizar los cambios mientras desarrollas.
